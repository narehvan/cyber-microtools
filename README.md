# cyber-microtools

A repository of random micro tools to help with cyber security activities.

**For each module, check the README.md file in the source directory for details**

| Tool    | Purpose |
| -------- | ------- |
| ip_cidr_generator  | Given IPv4 and CIDR, it generates a list of valid IP addresses    |
| ip_host_status_checker  | Given IPv4 and CIDR, it checks if the host is alive or dead   |
| cloudflare_email_deobfuscator | Decode/encode Cloudflare's email obfuscation |
| emailharvester | Scans a web page/file and extracts email addresses |
