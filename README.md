# cyber-microtools

A repository of random micro tools to help with cyber security activities.

**For each module, check the README.md file in the source directory for details**

| Tool    | Category | Purpose |
| -------- | ------- | -------- |
| cloudflare_email_deobfuscator | Web | Decode/encode Cloudflare's email obfuscation |
| emailharvester | Web | Scans a web page/file and extracts email addresses |
| ip_cidr_generator  | Network | Given IPv4 and CIDR, it generates a list of valid IP addresses    |
| ip_host_status_checker  | Network | Given IPv4 and CIDR, it checks if the host is alive or dead   |
| url2_webtreee_pretty  | Web | Turns a flat list of discovered URLs into an indented tree   |
